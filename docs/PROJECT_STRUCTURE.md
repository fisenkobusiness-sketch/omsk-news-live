# Архитектура проекта

## Единственный источник логики

Вся рабочая логика находится в `src/`. Корневые `analysis.py`, `predictor.py`, `live_monitor.py` — короткие переходники для старых настроек PyCharm и ручных команд. Они запускают соответствующий файл из `src/` и не содержат отдельной модели.

## Компоненты

| Файл | Назначение |
|---|---|
| `run_smm_poiskovik.py` | Запускает монитор и трекер согласованно |
| `src/live_monitor.py` | Сбор VK-постов, вызов стадий анализа, публикация пула |
| `src/analysis.py` | Первичная оценка, типизация, жёсткие редакционные фильтры |
| `src/predictor.py` | Итоговый рейтинг `editorial_v2` |
| `src/metrics.py` | Общие функции расчёта метрик |
| `src/smm_poiskovik_engagement_tracker.py` | Отдельный трекер вовлечённости |
| `tools/diagnostic.py` | Read-only диагностика |
| `tests/` | Регрессионные тесты |

## Контракт рейтинга

- Единственный итоговый рейтинг — `prediction.priority_score` (0–100).
- Версия модели в каждой оценке — `prediction.score_version = editorial_v2`.
- `score`, `viral_score` и `editorial_score` — диагностические поля старого анализатора, не самостоятельный итоговый рейтинг.
- Отсутствующие показатели не трактуются как нулевой интерес.
- Запрещённые темы, реклама и промо остаются жёсткими исключениями.
- Уверенность относится к проверке фактов и не повышает популярность материала.

## Производительность и устойчивость

- Независимые запросы к группам VK выполняются параллельно с ограничением числа рабочих потоков.
- Для VK предусмотрены таймауты и ограниченные повторы временных сетевых ошибок.
- Временные файлы и логи находятся в `runtime/`; секреты — в `.secrets/`.
- Публикуется только `editorial_pool.json`, без лишней записи устаревшего `final_queue.json`.
